0全局架构：一次抓取被拆成五个层级

人类"伸手抓方块"是一个动作，工程上被拆成 策略 → 任务 → 规划 → 控制 → 物理 五个独立层级。 本仓库每个层级对应独立模块，层与层之间通过明确的数据结构通信，这是机器人软件工程区别于"调脚本"的关键。

1机器人本体：7-DOF 冗余臂与平行夹爪

1.1 为什么是 7 个关节而不是 6 个

末端在空间中的位姿只有 6 个自由度（3 位置 + 3 姿态）。6 轴臂到达指定位姿时构型唯一； Panda 的 7 个旋转关节（joint1–joint7）多出 1 个冗余自由度：同一末端位姿对应无穷多组关节角， 机器人可利用这个"零空间"避障、避开关节极限、优化灵巧度。

本项目实测验证对末端 site 计算的 6×7 雅可比矩阵秩为 6，零空间维数 = 7 − 6 = 1， 与冗余理论完全一致（见第 4 节）。

1.2 自由度账本：nq=16、nv=15、nu=8

向量维度构成
qpos 广义位置167 铰链关节角 + 2 手指平动行程 + 方块自由关节（3 位置 + 4 四元数）
qvel 广义速度157 臂 + 2 指 + 方块 6 速度（3 线速度 + 3 角速度）
ctrl 控制量87 个手臂电机 + 1 个夹爪电机（一个电机经腱传动驱动双指）

关键记忆：铰链/平动关节占 1 个 qpos 和 1 个 qvel；自由关节占 7 个 qpos、6 个 qvel（四元数 4 个数但只有 3 个旋转自由度）；执行器数 ≠ 关节数。

1.4 三类几何对象：body / geom / site

  • body（连杆刚体）：携带 <inertial> 质量、质心、惯量张量，决定动力学方程的 M、g 项。如 link1 质量 4.97 kg。
  • geom（几何形状）分两类：visual 视觉网格 contype=0 只渲染不碰撞； collision 碰撞几何参与物理计算。指尖用 5 个小 box 近似软垫，比真实曲面网格接触更稳定。全模型 83 个 geom。
  • site（命名参考点）：无质量、不碰撞的纯坐标系标记。项目唯一的 ee_center_site 位于手掌内，是 IK 与观测读取的"末端点"。

真实 Panda 夹爪的双指由一个电机对中驱动，模型用三个机制还原：

2物理仿真：MuJoCo 每一步在算什么

2.1 带约束的刚体动力学方程

M(q)·q̈ + c(q,q̇) + g(q) = τ + JcT·fc
  • M(q)：广义质量矩阵（含连杆惯量与电机转子等效惯量）；
  • c(q,q̇)：科氏力与离心力项，转速越高越大；g(q)：重力项；
  • τ：执行器输出的广义力；JcTfc：接触约束经雅可比转置映射的等效力。

MuJoCo 把 c + g 合并存入 data.qfrc_bias（偏置力）——这是第 3 节重力补偿的关键。

2.2 数值积分：2 ms 步长与 implicitfast

仿真把连续微分方程离散成递推。步长太大刚体会在一步内"穿过"彼此，导致接触爆炸；本项目步长 0.002 s。 implicitfast 隐式积分器在更新速度时隐式考虑下一步的阻尼/接触力，比显式 Euler 稳定得多，且开销小。

模型还为每个关节配置 armature="0.1"（电机转子折算的等效转动惯量）与 damping="1" （黏性阻尼 N·m·s/rad），吸收高频振荡——真实电机本就存在转子惯量与摩擦，这是物理建模而非"作弊"。

2.3 软接触模型与方块参数

<!-- scene_with_cube.xml -->
<geom name="cube_geom" type="box" size="0.02 0.02 0.02"
      condim="4" friction="1.0 0.115 0.0001"/>
  • condim=4：1 个法向力 + 3 个切向摩擦分量（2 滑动 + 1 扭转）；
  • friction：滑动摩擦 μ=1.0、扭转 0.115、滚动 0.0001；
  • 方块质量 0.064 kg → 重力仅 0.628 N，不大的夹持力即可靠摩擦拿住；
  • MuJoCo 接触是软接触：靠 solref/solimp 生成随穿透深度增大的弹簧-阻尼法向力； data.contact 只记录当前帧（有效项 data.ncon），不保存历史。

3执行器模型与重力补偿

3.1 位置执行器本质是 PD 控制器

以 actuator1 为例：gainprm="4500" biasprm="0 -4500 -450"，MuJoCo 执行器输出 = gain 项 + bias 项：

τ = 4500·ctrl + (−4500·q − 450·q̇) = 4500(ctrl − q) − 450·q̇

这就是标准 PD 位置伺服：kp = 4500 N·m/rad，kd = 450 N·m·s/rad。 你写入的 ctrl 是目标关节角而非力矩；forcerange 模拟电机力矩饱和（大关节 87 N·m、腕关节 12 N·m）。

目标关节角 ctrl  →  PD 执行器  →  关节力矩 τ  →  动力学积分  →  实际 qpos / qvel
控制纪律arm_control.py 的 command_arm_joint_positions() 只写 data.ctrl， 绝不直接改 qpos——直接改 qpos 等于让机器人"瞬移"，绕过了全部动力学，不是真实控制。

3.2 重力（偏置）补偿：本项目最关键的控制细节

PD 增益按动态响应整定，而重力是恒定扰动，会让手臂在静止目标下依然下垂。工业机器人的标准解法是 前馈重力补偿：把当前姿态下抵消重力所需的力矩直接加上。

# arm_control.py —— 每个 mj_step 之前调用，因为 qfrc_bias 随 qpos/qvel 每步变化
def apply_arm_bias_compensation(scene):
    dof = _get_arm_dof_addresses(scene)
    scene.data.qfrc_applied[dof] = scene.data.qfrc_bias[dof]  # 前馈 c(q,q̇)+g(q)

实测 home 姿态各关节所需补偿力矩（N·m）：

[ 0.000 , −29.06 , 0.000 , 21.75 , 0.695 , 2.011 , 0.029 ]

joint2/joint4 靠近肩部、力臂长，承担整条手臂重量——与直觉一致。真机上 libfranka 同样提供 gravity / Coriolis 力矩向量做前馈。

4运动学：从关节角到末端位姿

4.1 三种旋转表示（项目全部用到）

表示维度项目位置特点
旋转矩阵 R3×3IK 目标姿态、site 的 xmat9 数含 6 约束（正交且 det=+1），便于坐标变换
四元数4 (wxyz)方块 free joint 状态、yaw_to_quaternion无奇异、插值平滑，适合存储
旋转向量 rotvec3rotation_error 的输出方向=转轴，模长=转角，适合做误差

姿态误差定义（rotations.py）：先求相对旋转 R_rel = R_target · R_currentᵀ，再取 rotvec 得到 3 维误差向量。 模块还严格校验 RᵀR=I 且 det(R)=+1，排除含镜像的非法矩阵。

4.2 正运动学（FK）

T0,ee(q) = T01(q1)·T12(q2)·…·T67(q7)·T7,ee

本项目无需手写变换矩阵：MuJoCo 在每次 mj_forward / mj_step 后沿运动学树自动算出所有 body、site 的世界坐标， data.site("ee_center_site").xpos / .xmat 就是 FK 结果，kinematics.py 只做干净封装。

4.3 雅可比矩阵：关节速度 ↔ 末端速度的线性映射

[ ve ; ωe ] = J(q)·q̇

get_ee_jacobian() 经 mj_jacSite 取出 3×7 线速度雅可比 Jv 与 3×7 角速度雅可比 Jw，堆叠为 6×7。两个核心概念：

  • 奇异位形：正常秩为 6（行满秩），末端可向任意方向运动；关节轴共线时 J 降秩，某些方向需要无穷大关节速度。冗余设计正是为减少奇异。
  • 冗余零空间：6×7 矩阵的零空间维数 = 1。存在非零 q̇₀ 使 J·q̇₀ = 0——末端不动、肘部自调整构型。

5逆运动学：阻尼最小二乘（DLS）

IK 回答"想让末端到达 (p*, R*)，7 个关节角该是多少"。7 轴 Panda 解析解繁琐，项目采用数值迭代的 DLS（Damped Least Squares，Levenberg–Marquardt 思路），实现在 ik.py。

5.1 推导：从伪逆到阻尼解

一阶近似 e ≈ J·Δq。普通最小二乘 Δq = J⁺e 在奇异附近伪逆爆炸。DLS 给目标增加关节运动量惩罚：

minΔq  ‖J·Δq − e‖² + λ²·‖Δq‖²
Δq = JT·(J·JT + λ²I)−1·e

对照 damped_least_squares()：先解 (JJᵀ + λ²I)·y = e 再返回 Jᵀy （用 np.linalg.solve 而非显式求逆，数值更稳定）。阻尼 λ（默认 0.01–0.05）的折中：λ→0 收敛快但奇异附近不稳；λ 大则平滑但变慢。

5.2 迭代流程与工程细节

  1. FK 读取当前位姿，计算位置误差 ep 与姿态误差 eo（rotvec）；
  2. 两者均低于容差（位置 1e-4 m、姿态 1e-3 rad）→ 成功；
  3. 每轮重算雅可比（姿态变 J 就变）；DLS 求 Δq；
  4. 单关节单步限幅 0.1 rad（位姿 IK 用整体等比缩放而非逐元素裁剪，保护位置/姿态任务的协调方向）；
  5. 裁剪到关节限位 → 写 qpos → mj_forward 重算 FK（不推进仿真时间）。
规划场景与执行场景分离IK 直接改 qpos 是纯运动学操作。 plan_pose_target() 新建独立 planning_scene（独立 MjData）跑 IK，只把目标关节角带回控制场景走动力学轨迹，防止机器人"瞬移"。

6轨迹生成与运动控制

IK 只给终点关节角，机器人不能瞬间跳过去，需要一条随时间变化的轨迹。

6.1 关节空间线性插值

linear_joint_trajectory() 用 np.linspace 在起终点关节角间等距插值，生成 N×7 航点（MOVE_ABOVE 用 201 个）。 选择关节空间而非笛卡尔直线插值，是因为每个中间点都保证是合法关节角、不会撞限位；代价是末端轨迹不是严格空间直线（本任务路径开阔，可接受）。 cartesian_trajectory.py 另提供笛卡尔航点 + 逐点 IK 方案用于需要直线接近的场合。

6.2 执行节奏与时间账

for 每个航点:
    写入 ctrl（PD 目标角）
    保持 10 个物理步（physics_steps_per_command=10）
        每步: 重力补偿 → mj_step
航点发完后 settle 250 步保持最终目标，消除残余振动
MOVE_ABOVE = 201 × 10 × 2 ms + 250 × 2 ms = 4.52 s（与实测逐位吻合）

settle_steps 稳定段让 PD 残余振荡收敛到验收容差（位置 2 mm、姿态 1°）以内。 move_end_effector_to() 返回结构化 MotionResult，按优先级报告失败原因： 非有限状态 → 关节越限 → 位置容差 → 姿态容差 → 成功，让每次运动都可客观验收。

7抓取任务的几何原理

7.1 自上而下姿态与 yaw 对齐

TOP_DOWN_GRASP_ROTATION = [[1,0,0],
                           [0,-1,0],
                           [0,0,-1]]

旋转矩阵的列 = 末端坐标轴在世界系中的指向：末端局部 +z（接近轴）指向世界 −z（竖直向下）， 局部 +y（夹爪张合轴）指向世界 −y。方块只随机化绕世界 z 轴的 yaw（±30°，保持直立）， top_down_grasp_rotation(yaw) 再左乘 Rz(yaw)，让夹爪水平轴跟随方块边缘旋转，保证两指平行于方块对侧面。

7.2 预抓取 / 抓取 / 抬升三点法（seed=42 实测坐标）

为什么是经典三点法把困难的接触运动限制在单一竖直方向：水平移动只发生在安全高度（pregrasp）， 接近与抬升都是竖直直线，显著降低碰撞与不确定性。

8接触感知与抓取成功判定

8.1 从 data.contact 到任务语义

引擎只给裸 geom ID，而指尖 geom 无名且每指由多个碰撞 geom 组成。contact.py 建立 body → geom 集合映射层解决：

body 名(left_finger / right_finger / cube) → body ID → 该 body 拥有的全部 geom ID 集合
每个接触项 (geom1, geom2) → 是否分别命中「手指集合 × 方块集合」（geom 顺序不固定，两个方向都查）

8.2 单帧接触 ≠ 稳定抓取：时间滤波

BilateralContactTracker 要求双侧接触连续保持 ≥ 0.1 s（50 个物理步）才计为持久接触， 中断一帧计数清零——本质是对二值信号做时间滤波，滤除擦碰毛刺。

8.3 摩擦握持的力平衡

方块重力 mg = 0.064 × 9.81 ≈ 0.628 N  ⇒  μ=1.0 时总法向夹持力 ≥ 0.63 N 即可

实测成功抓取后：左右指各 16 个接触点（共 32 个，指尖多 box geom 所致），单点法向力约 0.06 N、 总法向力约 1.9 N，裕量充足；方块–地面接触为 0。注意：接触条目数不是接触力，力须经 mj_contactForce 读取。

8.4 GraspMonitor 的两级多重判据

语义级别条件用途
grasp_candidate持久双侧接触 且 夹爪宽度 ∈ [0.005, 0.075] m闭合后、抬升前的放行检查
grasp_successcandidate 且 离地 ≥ 5 cm 且 线速度 ≤ 0.02 m/s、角速度 ≤ 0.2 rad/s 且 不触地最终验收

reason 按优先级输出未满足的首项（no_bilateral_contact / cube_not_lifted / cube_not_stable…），失败可诊断。 监测器只读不写，严格遵循观测与控制分离。

9任务编排：有限状态机（FSM）

pick_controller.py 用 9 状态 FSM 把全部能力串成完整任务：每状态做一件事，转移条件明确，失败可定位到具体阶段。

RESET 实测 1.50 s

回 home、采样方块、动力学自然落稳；落不稳 → FAILED(cube_not_settled)

MOVE_ABOVE 4.52 s

IK + 关节轨迹到预抓取点；IK 失败/越限/容差不达标 → FAILED

APPROACH 2.52 s

保持抓取姿态垂直下降到 grasp 点

CLOSE_GRIPPER 0.19 s

发闭合命令，最多等 1 s，形成持久双侧接触即提前结束

VERIFY_CONTACT 0 s 纯裁决

不发任何动作，只读监测器；非 candidate → FAILED（接触故障）

LIFT 2.52 s

保持闭合运动到 lift 点，全程监测；方块没离地 → FAILED

CHECK_SUCCESS 0.50 s

要求连续 0.5 s 全部满足成功判据，中断清零重来

DONE / FAILED 输出 PickResult

含每阶段成功标志、原因、耗时的完整记录

两个设计精髓 ① VERIFY_CONTACT 独立成态：README 的失败演示视频故意只让夹爪闭合一个物理步，FSM 在此正确拒绝抓取，证明故障检出真实有效； ② CHECK_SUCCESS 用连续成功帧而非单帧判定，防止方块瞬间离地又滑落被误判成功。

10可复现实验方法学

10.1 随机化与确定性

  • np.random.default_rng(seed) 创建局部 RNG，不污染全局随机状态，同 seed 永远产生同一位姿 （x∈[0.42,0.48] m，y∈[−0.06,0.06] m，yaw∈±30°）；
  • 方块先置于 5 cm 高度再靠真实动力学自然落稳（settle_cube），避免初始穿透；
  • reset_to_home() 是绝对写入而非增量调整，天然幂等，连 reset 10 次逐位相同；
  • 复位后自动断言关节限位与有限性（无 NaN/Inf），非法状态当场暴露。

11学习式路线：Gymnasium 与强化学习

11.1 观测向量（29 维，具名切片杜绝魔法下标）

[0:7]   手臂 7 关节角        [7:14]  手臂 7 关节速度      [14]    夹爪宽度
[15:18] 末端位置 xyz          [18:21] 方块位置 xyz          [21:23] 方块 yaw 的 sin/cos
[23:26] 方块线速度            [26:29] 方块角速度

yaw 用 sin/cos 连续编码，避免 ±π 处的角度跳变。

11.2 动作空间（7 维连续 ∈[−1,1]）与奖励

  • 3 维位置增量（每步最大 2 mm）+ 3 维旋转增量（每步最大 2°，旋转向量→旋转矩阵）+ 1 维夹爪宽度增量；
  • action_mapping.py 裁剪后映射为笛卡尔目标 → IK 转关节目标 → PD 执行；每个 env step 内含 10 个物理步（20 ms 决策周期）；
  • 奖励塑形：位置/姿态误差下降量（progress reward）+ 首次持久接触一次性 bonus + 抬升增量 + 成功 +5 大奖 − 动作能量小惩罚；
  • 终止语义：terminated = 任务自然结束；truncated = 达到 500 步上限被截断，不代表失败，bootstrap 处理不同。

11.3 两条路线共用同一套底层

脚本 FSM ─→ 运动原语 ─→ IK ─→ 关节位置控制 ─→ MuJoCo
SAC 策略 ─→ 笛卡尔增量动作 ─→ IK ─→ 关节位置控制 ─→ MuJoCo
诚实的基线SAC（最大熵强化学习）100k 步把平均误差从 789 mm 降到 86 mm，证明学到了有用的趋近行为， 但尚未达到成功阈值，且 Week 4 刻意只做 Reach（夹爪保持张开），不宣称掌握抓取。

14推荐复盘学习路径

  1. 建立直觉：读 docs/glossary.md 与 panda_xml_walkthrough.md，理解 XML → MjModel/MjData。
  2. 跑 home demo：运行 examples/panda_home_demo.py，对照第 2–3 节理解 ctrl / qpos / qfrc_bias。
  3. 手推 IK：读 ik.py 的 DLS，自己推导 Δq = Jᵀ(JJᵀ+λ²I)⁻¹e，再跑 Day 14 评测。
  4. 画状态机：读 grasp_task.py + pick_controller.py，手绘状态转移图。
  5. 攻克接触：读 contact.py，理解"为什么单帧接触不够"与多重成功判据。
  6. 看验收与视频：跑 day21/week3_acceptance.py，观看 results/day21/videos 的成功与失败演示。
  7. 进入 RL：读 continuous_env.py + rewards.py，理解环境四要素。
  8. 拓展挑战：给方块加质量/摩擦随机化、把关节插值换成笛卡尔直线、或加入力控奖励，向 Sim2Real 推进一步。

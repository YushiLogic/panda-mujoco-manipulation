# 名词手册（Glossary）

用法：看代码/文档遇到不懂的词 → 先查本表 → 表里没有就问 AI，并把新词补录进来。
每周末验收时，把本周新学的词补进对应分组，让这份手册跟着项目一起长大。

## 0. 全局地图（只看一张图的话看这张）

```
XML 文件（scene_with_cube ──include──> panda.xml ──引用──> assets/网格）
   │ from_xml_path 编译
   ▼
MjModel：结构规则（不变） ──┐
                           ├──> mj_step(model, data) 循环 ──> 机械臂运动
MjData：当前状态（每步重写）┘            │
    qpos(在哪) qvel(多快) ctrl(命令)    │
    ▼ viewer.sync() 把状态刷进窗口画面
```

三句话总纲：
1. **MjModel** = 这套世界的身体和物理规则，永不改变；
2. **MjData** = 世界"此刻"的唯一快照，每步被整体重写，历史不保存；
3. **qpos 决定从哪开始，ctrl 决定去哪，XML 决定服从什么物理**——三者谁也不是谁的目标。

## 1. Git 名词

| 名词 | 一句话解释 |
|---|---|
| 工作区 | 你正在编辑的文件本体（磁盘上的样子）|
| 暂存区 | "下一次提交"的草稿区；`git add` 把工作区改动复制进来 |
| 提交（commit）| 把暂存区内容冻结成一个永久历史节点 |
| 哈希（如 c196ad3）| 提交的唯一编号；由内容+时间等决定，所以同一改动重复提交哈希也不同 |
| HEAD | "你现在站在哪"的指针；`HEAD -> main` = 站在 main 分支的最新提交上 |
| 分支（main）| 指向当前最新提交的、会随提交前移的书签 |
| `git status` | 只读命令：报告工作区/暂存区/历史三者谁和谁不一致；迷路时先敲它 |
| `git diff` | 比较 工作区 ↔ 暂存区（"改了但没 add 的"）|
| `git diff --cached` | 比较 暂存区 ↔ 上次提交（"add 了但没 commit 的"）|
| `git add` | 工作区 → 暂存区 |
| `git commit -m` | 暂存区 → 历史，`-m` 后跟提交信息 |
| `git reset --soft HEAD~1` | 把分支书签拨回上一提交，改动完整退回暂存区（撤销提交不丢代码）|
| `git reset --hard` | 拨回书签**并销毁改动**（慎用）|
| `git restore --staged` | 把改动从暂存区拿回工作区（撤销 add）|
| untracked（`??`）| 新文件从未被 add 过，Git 还不认识它 |
| status 里 M 的位置 | 第一列 M=暂存区有改动；第二列 M=工作区有改动；A=新文件已暂存 |
| KeyboardInterrupt | Ctrl+C 强制中断的"现场照片"，不是 bug；干净退出=关窗口 |

## 2. MuJoCo 结构名词（XML 里的标签）

| 名词 | 一句话解释 |
|---|---|
| worldbody | 世界容器，XML 里唯一实质必写的段，所有物体都在里面 |
| body | 一个可运动的刚体"躯壳"：有名字、出生位置 `pos` |
| geom | 挂在 body 上的"外形+物理"：形状、颜色、摩擦、碰撞全靠它 |
| joint | **自由度声明**：宣告 body 相对父级允许怎样运动（不是零件，是许可）|
| HINGE / SLIDE / FREE | 转动（门轴）/ 滑动（抽屉）/ 自由（悬浮，6 自由度）|
| freejoint | FREE 关节的简写；无限位，宇宙中任何位置都合法 |
| site | 命名参考点：无质量、不碰撞，纯坐标系标记，可读取、可显示 |
| actuator | 执行器 = 旋钮：把 `ctrl` 数值变成力/目标（nu = 旋钮个数）|
| 位置伺服 | actuator 的工作方式：**持续**把关节拉向 ctrl 目标（"静止"=命令恰好等于现状）|
| tendon（腱）| 把多个关节打包成一条传动：`split` 把力五五分给双指 |
| equality | 约束：如左右手指位置强制同步 |
| keyframe | 模型内保存的命名状态快照（qpos+ctrl），像出厂自带的游戏存档位 |
| `<include>` | 编译期拼接：scene 文件把 panda.xml 拼进同一份模型再编译 |
| asset / mesh | 网格资源（stl/obj）；geom 引用它们获得真实外形 |
| rgba | 颜色：R、G、B、不透明度，各 0~1；`1 0 0 1`=纯红 |
| size（box）| **半边长**！MuJoCo 盒子写的是 xyz 各方向的一半（0.02 → 4cm 方块）|
| friction / condim | 滑动/扭转/滚动摩擦三元组 / 接触计算维数（4=含扭转摩擦）|
| ctrlrange / jnt_range | ctrl 的合法写入区间 / 关节限位区间 |
| default（class）| 默认参数模板，子标签自动继承（如 `class="panda"`）|
| mass（缺省时）| 不写质量则按 体积×1000（水密度）自动算：红方块 ≈ 64 g |

## 3. 状态与仿真名词

| 名词 | 一句话解释 |
|---|---|
| qpos | "每样东西**在哪**"：关节角/行程 + 自由物体 7 个数（xyz+四元数）|
| qvel | "每样东西**多快**"：角/线速度；自由物体旋转只占 3 维 |
| ctrl | 你写给执行器的**命令**数组 |
| nq / nv / nu | 上面三个数组的长度；本项目 16 / 15 / 8；nq−nv=1 是四元数多的那个数 |
| 四元数 (w,x,y,z) | 用 4 个数表示 3 维旋转（无奇异点）；(1,0,0,0)=不旋转 |
| qposadr | 某关节的数值在 qpos 数组里的**起始下标**（地址表，审计表里有）|
| 派生量 | 由 qpos 推算的量（site 世界坐标、接触列表）；写完 qpos **必须重算**才可读 |
| mj_step | 推进一小步物理时间（重算 + 积分翻页）|
| mj_forward | 只重算派生量、不推进时间（Excel 的 F9 键）|
| NaN / Inf | 非法数值（不是数/无穷大），数值仿真崩溃的前兆；`isfinite` 体检 |
| 不变量（invariant）| "必须永远成立的性质"（如 reset 后关节在限位内），由 assert 自动把守 |
| 幂等 | 调 1 次和调 100 次、调用前状态多脏，结果都逐位相同（reset 的设计要求）|
| viewer / launch_passive | 弹出可视化窗口并把控制权**交还你的 Python 循环**（窗口是被动的）|
| viewer.sync() | 把 data 当前状态刷进窗口画面；不调就不刷新 |
| viewer.is_running() | 窗口被关后变 False，主循环自然退出 |

## 4. 机器人学名词

| 名词 | 一句话解释 |
|---|---|
| 末端执行器 | 运动链最远端干活的部分（手爪）；本项目 = `ee_center_site` |
| TCP（工具中心点）| 末端上真正作业的那一点（手掌中心、两指之间），控制它而非手腕法兰 |
| 运动链 | 关节+连杆串成的链：link0→…→link7→hand→ee_center_site |
| 自由度（DOF）| 独立运动方向数；nv 就是全场景自由度总数 |
| 关节限位 | 关节允许的角度区间；joint4=[-176°, -4°]（肘部不能伸直，0 非法）|
| home 位姿 | 预定义的合法初始姿态；所有实验、episode 的统一起点 |
| 工作空间（workspace）| 末端能到达的空间范围（Panda 臂展约 0.85 m）；**合法 ≠ 可达** |
| 逆运动学（IK）| 给末端目标坐标反求各关节角（第 2 周主角）|
| 弧度（rad）| 角度单位：180°=π≈3.14159；-90°=-1.57079 |

## 5. Python / 工程名词

| 名词 | 一句话解释 |
|---|---|
| 子模块导入 | `import mujoco` 不会带出子模块；用 `mujoco.viewer` 必须先 `import mujoco.viewer` 点名 |
| @property | 把方法伪装成只读属性：`scene.ee_pos` 不用括号，每次读取实时计算 |
| 视图（view）vs 副本（copy）| 视图=内部数组的"直播画面"（会跟着仿真变）；`.copy()`=冻结的照片；**从 data 拿数组必 copy** |
| assert | 断言：条件不成立当场爆炸并报出具体原因；不变量的看门狗 |
| 退出码 | 程序结束时的 0（成功）/非 0（失败），供测试和 CI 判生死 |
| pytest | 测试框架：自动发现 `test_` 开头的函数并运行，无需 main |
| pytest.approx | 浮点专用相等断言（直接 `==` 比浮点是经典坑）|
| array_equal vs allclose | 逐位完全相等 vs 容差内近似（reset 验收故意用前者）|
| 广播（broadcast）| NumPy 把短数组"摊"进长数组的规则；形状不匹配报 ValueError |
| `raise SystemExit(1)` | 以失败状态结束进程（成功默认为 0）|
| argparse / Path | 命令行参数解析 / 跨平台路径对象（`parents[n]` 从文件位置反推目录）|

## 6. 本项目已排掉的雷（备忘，勿再踩）

1. joint4 默认 qpos0=0 非法（限位不含 0）→ home 用 -1.57079；
2. 原 keyframe 的 qpos/ctrl 在 joint6/7 不一致 → `HOME_CTRL` 已对齐 qpos（开机甩动根治）；
3. 夹爪量纲 0~255（**0=闭合，255=张开**，实测），与手臂弧度并存，勿混用；
4. box 的 size 是**半边长**（0.02 → 实际 4cm 方块，质量自动 ≈64 g）；
5. `data.qpos[:]` 整体赋值必须给满 16 个数（9 机器人 + 7 方块），否则广播报错；
6. 从 data 里拿数组必须 `.copy()`，否则是会跟着仿真变的"直播视图"。
